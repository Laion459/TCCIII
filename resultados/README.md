# resultados/

Artefatos gerados pelas execuções e experimentos (armazenamento local).

| Subpasta | Uso |
|----------|-----|
| `experimentos/condicao_a` | Saídas — extração nativa |
| `experimentos/condicao_b` | Saídas — OCR isolado |
| `experimentos/condicao_c` | Saídas — abordagem integrada |
| `metricas/` | Agregados de comparação com referência manual |

Cada execução cria, por PDF: `resultado.json`, `relatorio.txt`, `execucao.log`.

Por LGPD, PDFs e resultados completos **não são versionados** — ver `.gitignore`.
