# dados/entrada

PDFs utilizados no processamento e nos experimentos A/B/C.

- PDFs nativos ficam em `pdf nativo/`.
- `pdf-100-dpi/`, `pdf-200-dpi/` e `pdf-300-dpi/` são gerados por `scripts/gerar_pdfs_rasterizados.py`. O nome do arquivo permanece o do nativo, para reusar `dados/referencia_manual/`.
- Essas versões são digitalizações sintéticas (só imagem), não escaneamentos reais.
- **Não versionar** documentos com dados pessoais ou financeiros (LGPD) - ver `.gitignore`.
- Critérios de inclusão/exclusão: TCC 2 §5.8.

No repositório público permanece apenas este README; o corpus local fica na máquina do autor.
